# Bundled LUT starter pack

These five .cube files are bundled from **YahiaAngelo/Film-Luts**.

Source repository: https://github.com/YahiaAngelo/Film-Luts  
Source catalog: https://github.com/YahiaAngelo/Film-Luts/blob/main/film_luts.json  
License: MIT. The full license text is in LICENSE-MIT.txt.

Bundled starter files are available individually in this folder. The complete 15-look collection is in catalog.json, where each entry contains the full .cube text and its original filename.

The LUTs are provided as downloadable .cube assets. The current editor preset engine does not yet apply 3D LUT files in its live preview or final renderer; do not mistake these downloads for integrated LUT rendering.
